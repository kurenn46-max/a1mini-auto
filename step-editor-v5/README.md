# 岡重機 STEP Editor V5

FINAL RC1を残したまま追加した編集版。

## 主な編集機能
- 詳細面を選択して面を法線方向に伸ばす / 縮める
- 曲面を選択して穴径を広げる / 狭める（軸・径は自動推定）
- ↶ 戻る
- ↷ やり直す
- 元モデルへ戻す
- 編集履歴表示
- 編集後の仮STL保存
- ナイト用 .okacad 書き出し

## .okacad
ZIP互換の1ファイル。元STEPと edit.json を含む。
edit.jsonには編集対象の部品名、詳細面、位置、寸法、面積、編集量などを保存する。

## 注意
V5の画面上での編集は三角形メッシュを使ったプレビュー。
最終的な精密CAD/STLは .okacad の元STEPと編集指示を使って再構築する想定。
