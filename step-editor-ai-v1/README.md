位置づけ:
- AI系改良の第1基準点
- 第3基本版を土台にした文章操作版
- 今後のAI改良はこの版から枝分かれ
- このフォルダは原則変更しない

実装済み:
- STEP / STP / STL 読込
- 複数パーツSTEP認識

- 文章コマンド操作
- 選択パーツ削除

- Undo / Redo
- 軸解除
- 詳細面表示時の寸法混同修正
- 削除後の全体寸法表示
