# 岡重機 CAD NEXT

旧 STEP Editor を継ぎ足さず、新しい操作設計と編集コアを作るための独立プロジェクトです。

## 0.1 の目的
最初から本体形状を無理に変形しません。まず以下を安定させます。

1. STEP / STL 読込
2. 部品選択 / 詳細面選択
3. 選択面の正確なハイライト
4. 3軸 Gizmo 表示
5. X/Y/Z 数値入力
6. Undo / Redo
7. 編集コマンド履歴

0.1 の数値移動は黄色い選択面の安全なプレビューです。元 STEP/STL の B-Rep / mesh は変更しません。

## 次段階
- 0.2: 選択精度、穴・円筒・平面の分類
- 0.3: OpenCascade 系の実形状編集コア
- 0.4: Move Face / Offset Face / 穴径変更
- 0.5: 穴位置移動
- 0.6: AI 文から同じ編集コマンドを実行

## 設計方針
- Viewer / Selection / Edit / History / AI を分離
- UI と CAD 演算を分離
- 指ドラッグは粗調整、数値入力を最終値とする
- 旧安定版は削除しない
