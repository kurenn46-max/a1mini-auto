- PR #27 の検証済みソース: `ee2e651abbaa3a79e50247bab2e54cbcfa00bfd2`（V3.4.2）
- GitHub Actions run `38182781270`: Android APK署名確認・19件のネイティブ実G-code検査合格
- スマホ実機でユーザーが確認: 3MF読み込み、PETG235℃設定、スライス、3D Preview表示、回転、拡大/縮小、レイヤー表示切替、Job History

- プリンターを使用した実印刷は **これから**。未確認の実印刷を「合格」と表示しない

## 安全な正式リリースの条件
1. ユーザー立会いでA1 miniへ同一条件のリングを1回テスト印刷。送信前の実ファイル確認、ノズル/ベッド温度、開始処理、1層目、異常動作、完了品質を記録
2. テスト結果に応じて問題箇所のみ修正し影響する検査を再実行。生成G-code/フィラメント条件を変える場合、19件ネイティブ検査は再実施
3. 正式版のアプリ表示名を **NIGHT PRINT V4** に統一し、恒久的な applicationId / versionCode / versionName / 更新互換性を設定
4. Actionsの一時debug署名を正式版に転用しない。永続署名鍵をGitHub secrets等で安全管理し、キーをリポジトリ・ログ・ブラウザへ公開しない
5. APK / G-codeのSHA256を検証し、インストール・更新テスト、実機UI・履歴・レイヤー・保存・送信確認を行う
6. 安全上の未解決事項がないと確認してから安定版リリースを作成。安定版の告知にテスト未了の事項を紛れ込ませない

## 操作テストと正式版を分離

- 実機印刷で問題が出た場合は本ブランチで原因と対策を追跡し、成功後にV4として公開する
