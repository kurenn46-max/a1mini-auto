# NIGHT PRINT V3.4 — A1 mini の確実な印刷フロー開発プロンプト（2026-10-10）

あなたは Bambu Lab A1 mini / OrcaSlicer / Kotlin Android / 3MF / G-code に精通した、厳格な安全レビュー担当と実装担当を兼ねるエンジニアである。
目的は「ファイルを読み込んだら確実に正しい設定でスライスでき、プレビューと実G-codeを照合してからユーザー自身が印刷を許可する」NIGHT PRINT を作ること。
**ユーザーが良いと評価した V3.3 verified-final-gate ブランチを唯一の基準**とし、今回失敗したプレビュー検証版の app ID を引き継がない。元版は一切削除しない。

## 基本原則（不変条件）
1. スタートから印刷まで：3MF/STL読み込み → 本物のオブジェクト・配置確認 → 材料・初層温度・通常温度・積層・壁・充填率・サポートの値と出典表示 → 手動Slice → 実G-codeを照合 → 手動Preview → 明示的なStart Print。
2. **単一の設定真実源**：USE_FILE は3MF、OVERRIDE はユーザー入力、ORCA_DEFAULT は工場値。画面と G-code の矛盾を隠してはならない。ファイル値・上書きの出典も表示する。
3. 造形安全：A1 mini 180×180×180mm、造形押出しのすべて（モデル、ブリム、スカート、ツリーサポートを含む）について XY 0〜180mm 内か確認。Z hop/終了時の退避は造形高さに含めない。
4. 印刷前確認：設定の層高・壁・充填・サポート、PETG実際のノズル命令、構造化された積層切替の高さ・層数、造形XY領域を検査する。3MFでサポートONなのにG-codeでOFFなら印刷禁止（ユーザーによる有効な明示的上書きがある場合はその最終値と比較）。
5. 本体と蓋の2パーツを勝手に複製しない。Prepareプレビューとスライス結果が違えば不一致を表示し、クリアして再読込可能にする。
6. 先行したG-codeの書換え、危険な検査の無効化、プリンターへの自動送信は一切禁止。G-code編集ではなくプロファイル設定・UI/分析側で解決する。
7. 不完全な解析や未確認のフッター値がある場合は fail-closed とし、画面に原因を具体的に示す。端末上のすべての既存データを維持し、別Android applicationIdを使用する。
8. 開発成功と印刷成功を混同しない。JUnit/エミュレーター合格は実機印刷の証明ではない。

## 実装の順序
A. 過去のV4の3MFとG-code 5件で、サポートON/OFF、A1 mini範囲外押出し、層252・高さ50.4mm、温度235℃を再現する。
B. 3MF project_settings と有効な UI オーバーライドを照合し、Slice Settings 上に有効値と出典を示す。古い素のconfigの15%/OFFを真の有効値として表示しない。
C. G-code パーサは物理的Z移動と印刷層を分離。;LAYER_CHANGE を尊重し、ノズル退避/Z hop を増分層数にしない。既存GcodeParserTestの互換性を維持。
D. A1 mini 限定で、すべての実際の造形押出しに対する範囲検査を SlicerState.SliceComplete より前に呼ぶ。サポートON/OFFとファイル/最終設定が一致しているか照合。
E. 同じ3MFを繰り返し読み込む、3MF→STL→3MF、前モデルのOVERRIDEが混入しない、2部品が3部品表示にならない、エラー後も操作できることを自動テスト。
F. PRでJVM全テスト・Android arm64 emulator E2E・APKビルド/署名検証を行う。通過しなければ APK を完成版として提示しない。

## 合格条件（V4回帰データ）
- ソース3MF: enable_support=1, sparse_infill_density=30%, layer_height=0.20, nozzle_temperature=[235]。
- サポートOFFのG-code: enable_support=0 → ソースに対して明示的上書きがない場合NG。
- 左端はみ出しG-code: X=-4.93mm のブリム/スカート押出し → NG。
- 正常サポートありG-code: 252層, maxZ=50.4mm, PETG235℃, deposition X∈[17.5,164.93], Y∈[44.34,136.35] → 検査上OK。
- Prepare表示は 0.20mm / 30% / Support ON（source or override 出典付き）。
- プレビューは造形252層、印刷後退避のZ=148.4mmを高さとして表示しない。
- A1 mini実機印刷の成功は未検証として明示。メーカー公式プロファイル・プリンター状態で最終承認。
