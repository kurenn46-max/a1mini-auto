# 岡重機 STEP Viewer

Androidタブレット/スマホ向けの軽量3Dビューアです。

## 対応
- STEP / STP
- STL

## 主な機能
- STEPアセンブリのパーツ一覧
- パーツごとの外形寸法 X/Y/Z (mm)
- パーツ選択、単体表示、他パーツ半透明
- 分解表示
- 2点タップ距離測定
- 回転、ズーム、パン、全体表示
- ファイルはブラウザ内で処理し、サーバーへアップロードしません

## 使い方
1. 「開く」でSTEP/STP/STLを選択
2. 「パーツ」で部品一覧を表示
3. 部品を選ぶと外形寸法を表示
4. 「単体表示」または「他を半透明」で確認
5. 「測る」を押し、モデル上の2点を順番にタップ

## 注意
- STEP/STPはmmに変換して表示します。
- STL自体には単位情報がないため、このビューアではmmとして扱います。
- 穴径の自動認識は未実装です。現状は2点測定で確認します。
