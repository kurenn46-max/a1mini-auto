# 岡重機 STEP Editor AI実装 第4バージョン

固定元: AI実装 第3バージョン

追加機能:
- 丸い貫通穴を指でつかんで板面内をドラッグ移動
- 穴ドラッグ中は OrbitControls を停止し、穴位置編集を優先
- ドラッグ中に ΔX / ΔY / ΔZ を表示
- 指を離すと holeMove 編集として確定
- 穴径を維持
- Undo / Redo対応
- 外周に近づきすぎる移動は確定しない
- 通常面では従来の押し引きドラッグを維持

使い方:
1. 詳細面モードで穴の内周を選択
2. 「この面を編集」で確定
3. 「指ドラッグ編集 ON」
4. 穴の内周を指でつかんで移動
5. 指を離して確定

AI実装 第1〜第3版は変更せず保存する。
