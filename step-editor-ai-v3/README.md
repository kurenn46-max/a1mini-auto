# 岡重機 STEP Editor AI実装 第3バージョン

固定元: AI実装 第2バージョン

追加機能:
- 単純な丸い貫通穴の位置移動
- 穴径を維持したまま穴中心を平行移動
- ナイト文章指示
  - 「この穴を右へ2mm」
  - 「この穴を手前に3mm」
  - 「穴中心をX=15mm、Y=8mmに」
- Undo / Redo対応
- 穴軸方向への誤移動を拒否
- 外周に近づきすぎる移動を簡易肉厚チェックで拒否
- 穴中心座標を詳細欄に表示

制限:
- 第3版の穴位置移動は、単純な丸い貫通穴のみを対象にする
- 皿穴・ザグリ・段付き穴・複雑な連結穴は勝手に移動しない
- 外周安全判定は部品外形バウンディングボックス基準の簡易チェック

AI実装 第1版・第2版は変更せず保存する。
